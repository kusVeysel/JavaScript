### ⚡ JavaScript

JavaScript klasöründe, JavaScript'in temel konularından başlayarak orta ve ileri düzey konulara kadar uzanan kapsamlı bir konu yapısı bulunmaktadır.

Konular, öğrenme sırasına uygun olacak şekilde temel seviyeden ileri seviyeye doğru düzenlenmiştir. Değişkenler, veri tipleri, operatörler ve koşul yapıları gibi temel konuların yanı sıra fonksiyonlar, diziler, nesneler, DOM, olaylar, AJAX, Fetch API, Promise, Async/Await, OOP ve modern JavaScript yapıları gibi konulara da yer verilmiştir.

Konuların daha iyi pekiştirilmesi amacıyla, anlatımlar içerisinde çeşitli mini projelere de yer verilmiştir.

### 📌 Proje

`proje` klasöründe, JavaScript klasöründe anlatılan konuların bir arada kullanıldığı kapsamlı bir proje bulunmaktadır.

Bu proje ile konuların yalnızca ayrı ayrı öğrenilmesi değil, **gerçek bir uygulama içerisinde nasıl birlikte kullanılabileceğinin görülmesi** amaçlanmıştır.

Projede temel JavaScript yapılarından modern JavaScript özelliklerine, asenkron işlemlerden API kullanımına ve nesne yönelimli programlamaya kadar farklı konuların bir arada kullanılması hedeflenmiştir.

### 🎯 Amaç

Konular tamamlandığında **orta+ düzeyde** JavaScript bilgisine sahip olmanız hedeflenmektedir.
